# SalesTrackerPro

A modern sales tracking and quiz application built with React, TypeScript, and Node.js.

## Features
- Interactive quiz and results pages
- Modular UI components
- Server API with Express
- Shared types and schemas
- TypeScript throughout

## Getting Started

### Prerequisites
- Node.js (v16+ recommended)
- npm or yarn

### Installation
```bash
git clone https://github.com/yourusername/SalesTrackerPro.git
cd SalesTrackerPro
npm install
```

### Running the App
#### Development
```bash
# In one terminal, start the server:
npm run dev:server

# In another terminal, start the client:
npm run dev:client
```

#### Production
```bash
npm run build
npm start
```

## Project Structure
- `client/` - React frontend
- `server/` - Node.js backend
- `shared/` - Shared types and schemas
